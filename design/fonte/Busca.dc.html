WebContentsView

Uma WebContentsView mostra conteúdo web dentro de uma janela. Ela é uma view como qualquer outra: você cria, define a posição e adiciona à árvore de views da janela.

Cada view carrega seu próprio webContents, com navegação, histórico e processo de renderização independentes. Por isso é a peça certa para representar uma aba.

Para trocar de aba, mude qual view está visível ou remova a anterior da janela. Destruir o webContents de uma aba parada libera a memória do processo dela.

As preferências de segurança são definidas ao criar a view, em webPreferences, e não mudam depois.
